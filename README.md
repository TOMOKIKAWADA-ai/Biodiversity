# 小さな流域 — 生物多様性ジオラマ

Three.js で作った、生物多様性を観察するための仮想自然空間のプロトタイプです。
蛇行する川のある小さな土地で、季節がめぐり、植物が育ち、湿地・草地・林が生まれ、
虫・魚・鳥が暮らし、外来種の侵入と人の保護活動のせめぎ合いを
ジオラマのように眺められます。

勝敗のあるゲームではなく、**教育・展示・企画検討用の「眺める」プロトタイプ**です。
研究用の厳密な生態系モデルではありません。

## プロジェクトの目的

- 生物多様性を「生きものの数」だけでなく、**環境の種類・植物の種類・環境同士の境目(エコトーン)の豊かさ**として見せる
- 川 → 湿り気 → 植生 → 虫・魚 → 鳥 という関係のつながりが、画面を眺めているだけで伝わるようにする
- 外来種(アレチウリ)の広がりと、**早期駆除・保護の効果**を体験できるようにする
- 生きものの視点(鳥・魚・虫)から環境のつながりを感じられるようにする

## 起動方法

Node.js (v18 以上推奨) が必要です。

```bash
npm install
npm run dev
```

表示された URL(通常 http://localhost:5173)をブラウザで開きます。

本番ビルドする場合:

```bash
npm run build
npm run preview
```

依存は実行時 **Three.js のみ**、開発時 **Vite のみ**です。

## 操作方法

| 操作 | 内容 |
|---|---|
| ドラッグ / スワイプ | 視点を回す(しばらく触らないとゆっくり自動回転) |
| ピンチ / ホイール | ズーム |
| 地面をクリック / タップ | 手入れする範囲を選ぶ。範囲内の外来種の有無が画面下部に表示される |
| ⏸ 停止 / ▶ 再開 | 時間を止める・進める |
| ⏩ 速さ | 時間の速さを ×1 → ×2 → ×4 で切り替え(日数の進みだけを速め、生きものの動きは自然なまま) |
| 🌧 雨 | 雨を降らせる(土が湿り、湿地側の植物が元気になる)。短時間に連打すると土が飽和して川が氾濫する |
| 🌊 氾濫 | 川を氾濫させる(自然の攪乱の再現)。低地の植物が押し流され、水が引くと埋土種子が一斉に芽吹く |
| 🌱 植える | 選んだ範囲の適地に種をまく(湿った場所はヨシ、それ以外は草・花) |
| 🌿 外来種を抜く | 選んだ範囲のアレチウリを抜く。対象がある時だけ押せ、**早い段階ほどよく効く** |
| 🛡 保護 | 約100日のあいだ、希少種が生き残れる環境を見守る |
| 👁 視点 | 観察 → 鳥 → 魚 → 虫 の視点モードを切り替え |
| ↺ リセット | 初期状態からやり直す(地形は同じ、植生の配置は変わる) |

画面上部の半透明パネルに
**季節 / 時間 / 植物数 / 多様性 / 水辺の豊かさ / 虫 / 鳥 / 魚 / 外来種(侵略度+生活史ステージ) / 種子バンク / 翌年リスク / 駆除難度 / 希少種(数とリスク)** を表示します。

## 今回追加した要素

- **季節**(春・夏・秋・冬の循環と、光・色・生きものの活動の変化)
- **虫の強化**(植物にとまる・飛び立つ行動)
- **魚**(川の中を泳ぐ。水辺の豊かさで増減)
- **鳥の強化**(虫と魚を「近づく→狙う→捕る→離れる」で捕食)
- **侵略的外来種アレチウリ**(時間経過で自動侵入し、在来植物を覆う)
- **希少種**(条件のよいエコトーンにだけ低確率で出現)
- **人為的保護**(保護・駆除ボタン)
- **生きもの視点モード**(鳥・魚・虫の目線で空間を見る)
- **氾濫(自然の攪乱)と埋土種子バンク**(展示用に🌊ボタンでも発動可能。大雨でも自然発生)

## シミュレーションの内容

64×64 のセルグリッドで簡易シミュレーションを回しています(1 ティック = 1 日 ≒ 実時間 0.45 秒)。

### 地形・環境

- ノイズによるゆるやかな起伏 + 蛇行する川。川から離れるほど少し高くなる
- 湿り気は川からの距離 + ノイズ + 雨で決まり、裸地 / 草地 / 湿地 / 低木地 / 林が分かれる
- 各セルのバイオームの「境目」の数をエコトーンとして数える

### 季節

- **30日 = 1季節、120日 = 1年**(実時間で約54秒)で春→夏→秋→冬が循環し、UIに表示
- 季節の変わり目では、数値も色もなめらかにブレンド
- **春**: 植物の成長が最も速く、虫や鳥が増え始める
- **夏**: 成長が活発。虫・魚・鳥の活動が最も活発
- **秋**: 成長が落ち着き、草・ヨシ・木の色が黄みがかる
- **冬**: 成長はほぼ止まり、虫は大きく減り、鳥と魚の動きも落ち着く。光が冷たく淡くなる
- 見た目は、太陽光の色と強さ、霧の色、地表の緑、植物の色味が季節でゆるやかに変化

### 植物(在来種 5 種)

- **草**: 湿り気が中程度の場所に広く拡散
- **ヨシ**: 湿った川沿いに集中して群生(エコトーンの帯)
- **花**: 草地が安定すると混じる(秋冬は減る)
- **低木**: 草地が約30日安定すると出現
- **木**: 約70日安定した場所で低木や近くの木を足がかりに増える(遷移)
- 枯れた植物は土の栄養に還り、次の成長を後押しする
- **埋土種子バンク**: 生育中の植物は土の中に種を残す(草・ヨシ・花ごとに蓄積、ゆっくり減衰)。初期の土壌にも休眠種子が眠っている

### 氾濫(自然の攪乱と再生)

- 🌊ボタンで発動できるほか、**雨を短時間に連打して土が飽和すると自然に発生**する
- 水位が約14秒かけて上昇→滞留→後退し、標高の低い川沿いの土地だけが濁流に沈む(川面も土砂で濁る)
- 押し流しは種ごとに差がある: 草・花はほぼ全滅、低木・若木も流される。**ヨシは流れに比較的強く、成木は根で耐える**。**濁流はアレチウリも流す**
- 氾濫原の希少種はダメージを受ける(湿地・水辺タイプは増水にやや強く、草地タイプは弱い)
- 植生の安定度はリセットされ、遷移(草地→低木→林)はやり直しになる
- 水が引くと土砂(シルト)が栄養を運び、土はしばらく湿ったまま
- その後約30日間の「発芽パルス」で埋土種子が一斉に芽吹く。**攪乱地ではまずパイオニアの花が咲き**、草・ヨシが続く(冬は芽吹きが遅い)
- 氾濫を繰り返すと種子バンクが枯渇していき、回復が遅くなる

### 虫

- 草・ヨシ・花の量、エコトーンの多さ、**季節**に応じて増減(春夏に多く、冬はほぼいなくなる)
- 草地・湿地・水辺の近く、特に**環境の境目**に出やすい
- **植物にとまる行動**: 飛びまわる → 植物に近づく → とまって休む → 飛び立つ、を繰り返す
  - 植物密度が高いセルほどとまりやすい
  - とまる高さは草・ヨシ・低木の高さに応じて変わる
- 鳥に狙われると逃げるように速く動く
- アレチウリに覆われた場所では減る

### 魚

- **川の中だけ**に現れ、背中が水面に少し出る形でゆっくり泳ぐ(左右に揺れ、向きを変える)
- 出現条件: **水辺の豊かさ**(ヨシの茂み+水辺の境目)が高いほど増える
- アレチウリの侵略度が上がると減る(水辺環境の単純化)
- 季節で活動量が変わる(夏は活発、冬はゆっくり・少なめ)
- 鳥に狙われると速く泳いで逃げようとする

### 鳥

- 出現条件: **虫がある程度いること** + 多様性が高いこと。**魚がいるとさらに増えやすい**
- 季節で数が変わる(春夏に多く、冬は少ない)
- ふだんは上空をゆっくり旋回し、ときどき狩りをする
- **捕食アニメーション**:
  - 虫: 旋回 → 虫に向かって降りる → 追って捕る → 上空へ離脱(虫が1匹減る)
  - 魚: 旋回 → 水面に向かって降下 → 水しぶきを上げて捕る → 飛び立つ(魚が1匹減る)
  - ワープせず、「近づく→狙う→捕る→離れる」の流れが見えるようにした

### 侵略的外来種: アレチウリ(季節性・種子バンクモデル)

アレチウリは**一年草のつる植物**として、個体数(繁茂量 biomass)だけでなく、
**季節に沿った生活史(stage)** と **土壌中の種子バンク(seedBank)** を持つモデルにしています。

#### モデル化の概要

各セルが次の状態を持ちます(コード上の対応):

| 概念 | 実装 | 内容 |
|---|---|---|
| 繁茂量 biomass | `vine[i]` | その場の地上部の量(0〜1) |
| 種子バンク seedBank | `vineSeed[i]` | 土壌中に残った種の量(年をまたいで残る) |
| 被覆 coverRadius/cover | `vineCover[i]` + 隣接拡散 | 在来植物を覆っている度合い |
| 生活史 stage | `vinePh.stage`(年内経過日から計算) | 芽生え/伸長/繁茂/結実/枯死 |
| 駆除難度 removalDifficulty | `metrics.removalDifficulty` | 繁茂量・大株度から算出 |

#### 季節ごとの挙動

年(120日)を生活史で区切っています。

- **春(芽生え)**: 前年の**種子バンクから低確率で発芽**。種子バンクが多い場所ほど発芽が多い。株は小さく(上限0.28)、被害は弱い。**駆除が非常に効き、種子バンクも減らせる**
- **初夏(伸長)**: つるが伸び始め、隣のセルへ広がり始める(上限0.52)。まだ駆除がよく効く
- **夏(繁茂)**: 成長が速くなり(上限1.0)、周囲の在来植物に絡みついて覆う。覆われた植物は光不足で成長が止まり、やがて枯れる
- **晩夏〜秋(結実)**: 大繁茂し、十分茂った株が**種子バンクを大きく増やす**。**この時期以降の駆除は、地上部は減っても翌年の種子は残る**(被害の先送り)
- **冬(枯死)**: 地上部は枯れて消える。**ただし種子バンクは土に残る**。UIの「種子バンク」「翌年リスク」で残存が分かる
- **翌春**: 残った種子バンクから再び発芽。**前年に秋まで放置した場所では翌年の発生地点が増え、春〜初夏にこまめに駆除していた場所では翌年の発生が少ない**

#### 自動侵入(ボタンなし)

外部からの偶発的な種子の侵入として、時間経過で自動的に起こります。

- 川沿い・裸地・草地の縁・**湿り気のある場所**・植生の弱い場所に入りやすい
- **雨のあとは侵入確率が上がる**
- デバッグ用に発生確率を調整できる定数を用意しています(`src/main.js` 冒頭付近):
  - `VINE_INVASION_START_DAY`(既定45): この日数を過ぎると侵入が始まる
  - `VINE_INVASION_RATE`(既定0.016): 1日あたりの新規侵入確率。大きいほど侵入が早い
  - `VINE_SPRING_GERM_RATE`(既定0.05): 春の発芽係数(種子バンク量に比例)。大きいほど翌年の再発生が多い
  - `VINE_SEED_PRODUCTION`(既定0.05): 結実期に繁茂量から種子バンクへ変換される量。大きいほど翌年リスクが増える

#### 在来植物・希少種・生きものへの影響

- 覆われた在来植物(草・ヨシ・花・低木・若木)は**成長が止まり、被覆が続くと枯れる**
- アレチウリ地は環境タイプ数・エコトーンに数えない(**環境の単純化**)→ 多様性が直接下がる
- 在来植物が減る → **虫が減る**/水辺植生が単調になる → **魚が減る**/虫・魚が減る → **鳥も減る**
- 希少種は**通常の在来植物より早く弱る**。繁茂した場所では新規出現確率も下がる

#### UI 表示

- **外来種**: 侵略度(%)+ 現在の生活史ステージ(例「12% 繁茂」)
- **種子バンク**: 少 / 中 / 多
- **翌年リスク**: 低 / 中 / 高(種子バンク + 結実中の繁茂量)
- **駆除難度**: 低 / 中 / 高(総量・大株度・結実後かどうか)

### 希少種

- 抽象化した希少種として 3 タイプ(湿地の希少植物 / 草地の希少植物 / 水辺の希少生物)
- **出現条件**(すべて満たした場所に低確率で出現、最大5):
  - 多様性 55 以上、エコトーン(境目)が多い、アレチウリが少ない
  - 出現場所自体がエコトーンのセルで、在来植生があること
- **消える条件**: 周辺にアレチウリが広がる、在来植生が減る、多様性が下がる
- 健康度を持ち、環境が悪いとゆっくり弱って姿を消す
- 見た目は、淡く光る小さな花と、ほのかな光の輪(派手にしない)
- UIに **数とリスク(低/中/高)** を表示
  - リスクは、侵略度と健康度から計算(「高」は外来種の脅威が迫っているサイン)

### 人為的保護(保護・駆除)

- **🧹 駆除**: アレチウリを刈り取る。**効果は生活史ステージで変わる**
  - **芽生え・伸長**:ほぼ根絶でき、種子バンクも減らせる(早期駆除が最も有効)
  - **繁茂**:一部だけ除去。大株ほど取り残しが多く、回復に時間がかかる
  - **結実後・枯死**:地上部は減らせても**種子バンクは土に残り、翌年に発芽する**(「土の中に種子が残っています」と表示)
  - 希少種の周り(半径7セル)は優先して手厚く除去
  - → **春や初夏にこまめに駆除すると、夏以降の大繁茂と翌年の被害をかなり抑えられる**。秋まで放置すると駆除の費用対効果が下がる
  - 種子バンクは結実がなければ**自然に失活していく**(約1年で6割ほどに減る)。早期駆除を続けて毎年の結実を止めれば種子が補充されないため、**翌年リスクが「高」→「中」→「低」と1〜数年で下がっていく**。逆に毎年結実を許すと種子バンクが積み上がり、なかなか下がらない(全域が長年放置された土地の回復はとくに時間がかかる)
- **🛡 保護**: 約100日のあいだ保護活動がつづく(ボタンが「保護中」になる)
  - 希少種の健康度がゆっくり回復しやすくなる
  - 希少種の周りでアレチウリの拡大を強く抑える
  - 希少種の周りの在来植生の回復を助ける
  - 保護中は希少種が新たに現れる確率も少し上がる
- 希少種は「保護すればすぐ増える」ものではなく、**環境が整っていないと回復はゆっくり**

## 視点モード

👁 ボタンで **観察 → 鳥 → 魚 → 虫** の順に切り替わります。

| モード | 見えるもの |
|---|---|
| 観察 | これまで通りのジオラマ全体。ドラッグ/スワイプ/ズーム可 |
| 鳥 | 鳥の少し後ろ上から追従。川・草地・林のつながりが見える。狩りが始まると視点も獲物に寄る。狩り中の鳥を優先して追う |
| 魚 | 水面近くを泳ぐ魚に追従。川沿いのヨシや湿地が魚のすみかに見える。鳥に狙われると逃げる様子も見える |
| 虫 | 地表すれすれの低い視点。植物が大きく見え、虫が植物にとまる・飛び立つ様子を間近に見られる |

- 生きもの視点ではカメラがゆるく追従し(急な動きやワープはしない)、観察ボタンでいつでも戻れます
- **対象がいない場合**(例: 冬で虫がいない)は「まだ◯◯がいません」と表示して観察に戻ります。追従中に対象が消えた場合も同様
- 鳥視点では虫と魚がほんの少しだけ見つけやすい色になります(派手なマーカーは使わない)

### 視点モードで見られる生態的な関係

- 鳥視点: エコトーンの多い場所ほど虫や魚が見つかる/捕食の一部始終
- 魚視点: 川沿いの植生(ヨシ)と水辺の豊かさ/上空からの捕食リスク
- 虫視点: 植物が足場や休み場所になること/植物の密度と虫の活動の関係

## 多様性指標について

0〜100 の簡易スコアです(研究用の指標ではありません)。

| 要素 | 重み | 内容 |
|---|---|---|
| 植物の種類数 | 35% | 草・ヨシ・花・低木・木のうち定着している種類 |
| 環境タイプ数 | 25% | 水・湿地・裸地・草地・低木地・林(アレチウリ地は数えない) |
| 境目の多さ(エコトーン) | 25% | 隣接セルのバイオームが異なるペアの数(アレチウリ地は除外) |
| 生きもの | 15% | 虫・鳥・魚がいるか |

さらに**侵略度に応じた減点**があり、アレチウリが広がると多様性が直接下がります。

「水辺の豊かさ」は、ヨシの茂みの量と、水・湿地に接する境目の数から計算しています。

## シミュレーション上の関係(まとめ)

```
季節 ──→ 植物の成長・色 ──→ 虫(植物にとまる)──→ 鳥(虫を捕食)
  │           │                                ↑
  │           └→ 水辺の植生 ──→ 魚 ────────────┘(魚も捕食)
  │
  └→ アレチウリの拡大速度(暖かい季節に速い)

アレチウリ ──→ 在来植物を覆う ──→ 多様性・エコトーン低下 ──→ 虫・魚・鳥が減る
     │                                            │
     │                                            └→ 希少種が消えやすくなる
     └← 駆除(早期ほど有効) / 保護(希少種の周りを守る)
```

## 残っている課題

- 鳥の狩りの頻度・成功率は固定的(獲物が逃げ切ることはない)
- 虫は1種類の表現のみ(蝶・トンボなどの区別がない)
- アレチウリの「つるが植物に絡みつく」表現は簡易(地表のもつれで表現)
- 希少種のラベル表示(近づいたときに名前が出る)は未実装
- 視点モードで追従する個体は選べない(常に同じ個体)

## アレチウリのモデルにおける単純化

教育用に分かりやすさを優先しているため、現実とは次の点で異なります。

- 生活史のステージは「年内の経過日」だけで決めており、気温・日長・個体ごとの成長差は考慮していません
- 種子の散布(動物・水・人による運搬)は隣接セルへのにじみ出しに簡略化しています
- 種子バンクの寿命や埋没深度、発芽率の年変動は一律の係数で近似しています
- つるの巻きつきは「被覆による光不足」として面的に表現し、個々の巻きつき構造は再現していません
- 駆除の効果はステージ別の固定係数で、刈り取り方法や根の除去の違いは区別していません

## 参考・法的扱いに関する注意

- **アレチウリは特定外来生物です。** 現実には、栽培・保管・運搬、野外へ放つ・植える・まくことなどが**原則禁止**されています(外来生物法)。
  本プロトタイプは**教育用の仮想シミュレーション**であり、現実の取り扱いを勧めるものではありません。
- 防除は法令・自治体の手引きに従って行う必要があります。実際の対策では、**結実(種子をつける)前の早期防除**が重要とされており、本シミュレーションの「早期駆除が有効」という挙動はその考え方を簡略化して表したものです。
- 本プロトタイプの生態的な挙動はすべて簡略化されたものです。
  **実在種(アレチウリや特定の希少種)に置き換えて教材化する場合は、生態の専門家による監修が必要です。**
- 数式の正確さより「関係が見えること」を優先しています。
